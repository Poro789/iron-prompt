## 功能

- **今日训练页** — A/B 日计划，逐组重量/次数/时长/RPE，点按确认，确认第一组后自动计时
- **± 步进改数值** — 重量按设置里的步进、次数 ±1、时长 ±5 秒；训练中不必调出键盘，精确值仍可直接输入；桌面/键盘场景下重量框按回车跳到次数框、次数或时长框按回车提交并完成这一组
- **上次的数值就在眼前** — 正式组卡片上显示上次做到多少（力量按最重、计时按最长、自重按最多，带日期），点一下「沿用」填进这一组，再用 ± 往上加；热身组不显示
- **计时动作的秒表** — 平板、拉伸、呼吸这类按秒记的动作，按一下开始计时、再按一下把秒数填进这一组；直接按确认也会自动停表填入
- **自动保存** — 数据仅存浏览器 localStorage，每次修改即存，不上传任何服务器；刷新或被系统回收后，已输入的数值和停在第几组都还在；组间休息倒计时和秒表按时间戳持久化，重开浏览器也能接着走
- **全量备份 / 恢复** — 下载一个完整数据文件（日志 + 计划 + 动作库 + 进行中的记录 + 设置），换设备时用同一个文件恢复；「清除全部数据」在动手前会尽力把这份备份塞进剪贴板，误清后还能粘贴留底
- **导出给 AI** — 一键生成分析 prompt：固定背景 + 休息偏好说明 + 最近 N 次日志（含状态/完成标记）+ 逐动作趋势（回看 12 次）+ 严格输出模板，粘贴给 AI 即可；复制后显示字符数，数据多了可以少导几次
- **导入 AI 方案** — 粘贴 AI 返回的 JSON（容忍 ```json 包裹与多余逗号），只更新计划与动作库，不动日志；导入前会先列出会改什么（哪些动作增减、目标怎么变），导入后可以「撤销上次导入」
- **状态与完成标记** — 记录当日整体状态（佳/一般/差）；未完成组保留 done 标记，不计入容量与趋势
- **结束后可以反悔** — 结束训练的小结里有「改一下」：把这次记录原样放回编辑态，改完再点结束，不必重录一遍；「不要了」丢弃也支持 6 秒撤销，改坏了被丢弃时原记录会自动回来
- **历史记录也能改** — 历史里展开任意一条记录点「改一下」，原日期与起止时间保持不变，改完重新结束即覆盖该条
- **删除某次记录** — 历史里展开一条记录，末尾有「删除这次记录」，试训或填错的可以清掉；删除要先确认，删掉后 6 秒内在提示条里可以撤销
- **动作个人备注** — 设置页可为每个动作写个人注意（伤病、体感），卡片「要点」区显示；导入新方案时本地备注会被保留
- **趋势图** — 历史页按指标分组（重量 / 时长 / 次数各一张图）画出每个动作最好一组的走势，图例给出最新值、方向与记录次数
- **组间休息倒计时** — 确认一组后自动开始，进度条 + ±15s + 跳过，结束响铃并震动；基于时间戳，切后台再回到前台会立即纠正显示
- **可安装离线使用** — PWA（manifest + service worker），添加到主屏幕后离线可用

## 数据（四层，不混存）

| 层 | 内容 |
|---|---|
| `logs` | 训练日志：日期/动作/组（重量·次数·时长·RPE·done·side）/当日状态/用时 |
| `exercises` | 动作库：肌群/模式/单位/要点/避坑/节奏/替代/个人注意 |
| `program` | A/B 日计划：分区、逐组规格（热身/正式、重量/次数/时长/目标 RPE） |
| `sessions` | 进行中的记录（按 A/B 分存，结束前不写入 logs） |
| `drafts` / `condDraft` / `ui` | 草稿（输入了但还没确认的组）、会话前的状态选择、停在第几组 —— 刷新或崩溃都不丢 |
| `rest` / `timer` | 进行中的组间休息与秒表（只存时间戳，重开浏览器接着走） |

导出快照由 logs 即时打包生成，不单独存储。

## 已知限制

- **单浏览器存储**：数据只在本机 localStorage，不会自动同步，也没有多端合并机制。换设备/换浏览器走手动备份：「历史 & 导出 → 备份与恢复」先下载备份文件，在新设备上用同一个文件恢复。注意「导出给 AI」的快照只含最近 N 次日志，不能当备份用。
- **趋势方向是启发式**：`up` / `down` 需首尾与后半段均值同向；会话数 ≥ 6 时再校验近 3 次均值，否则判为 `plateau`。它是给 AI 的提示，不是医学结论。

## 结构

```
index.html            结构（无内联 CSS/JS）
css/style.css         样式
js/app.js             逻辑（APP_VERSION 唯一来源）
manifest.webmanifest  PWA 清单
icon.svg              图标（矢量；浏览器标签用）
icon-192.png          安装图标 192
icon-512.png          安装图标 512（同时用作 maskable）
apple-touch-icon.png  iOS 添加到主屏幕（iOS 不认 SVG，只认 PNG）
sw.js                 离线缓存（缓存版本串由 CI 按 APP_VERSION 改写）
fixtures/plan-A.json  测试夹具（一份真实 A 日计划）
```

零构建：无打包器、无依赖，`css`/`js` 直接外链。测试用零依赖 DOM 桩直接加载 `js/app.js`，并按文本核对 `index.html` 的接线（id/data-act）。

## 开发

```bash
node test-ironlog.js   # DOM 桩逻辑测试（零依赖）
npx serve .            # 本地预览（SW 需要 http，file:// 下不注册）
```

推送 main 自动部署 GitHub Pages。`sw.js` 的缓存版本串由 CI 用 `APP_VERSION` 自动改写；本地改版本后无需手动同步（测试会校验两者一致）。
